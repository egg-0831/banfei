# 知识库文档 · 班级账务口径

> **用途**：上传到连小理知识库，作为工作流「分类」节点的判断依据。
> 可见范围：设为班级内部可见。
> 原则：**只放口径，不放数据。** 任何个人缴费信息都不进这里。

---

## 一、角色与边界

- 使用者是**班级生活委员**，工具是**辅助记账与公示**的助手。
- 本工具**只做信息的记录、核对与公示**：
  - **不执行支付、不收款、不代收代付**；
  - 所有真实资金动作由人在工具之外完成；
  - 审批类决定由**人**做出，工具只负责转达与留痕。
- 遇到与资金收付相关的请求，一律回复：本工具不处理资金收付，请线下完成后再来登记。

---

## 二、支出分类标准

共 **4 类**，必须归入其中之一，**不允许自造类别**。

| 类别 | 判定标准 | 典型例子 |
|---|---|---|
| **团建活动费** | 为集体活动发生的费用，含场地、物料、零食饮料、交通 | 团建买零食、破冰活动场地费、集体出游车费 |
| **学习资料费** | 为全班学习用途统一采购或制作的费用 | 统一打印复习资料、购买实验报告册、共享教辅 |
| **班级公共支出** | 班级日常公共消耗与公共物品 | 纸巾垃圾袋、班级绿植、班会物料、公共文具 |
| **其他** | **仅当下述三类都不成立时**才使用，且必须在备注里写清用途 | 无法归入前三类的零散支出 |

**分类优先级**：先判断「是否与集体活动相关」（团建）→ 再看「是否直接用于学习」（学习资料）→ 再看「是否班级日常公共消耗」（公共支出）→ 都不成立才用「其他」。

---

## 三、容易混淆的情况

| 情况 | 归入 | 理由 |
|---|---|---|
| 班会买零食 | 团建活动费 | 属集体活动物料 |
| 班会打印议程表 | 班级公共支出 | 属班级日常事务，非学习资料 |
| 打印期末复习提纲 | 学习资料费 | 直接服务全班学习 |
| 班级绿植 | 班级公共支出 | 公共环境物品 |
| 集体观影门票 | 团建活动费 | 集体活动 |
| 给某位同学垫付的费用 | **不入账** | 属个人之间往来，与班费无关；应提示"不入班级账" |

## 四、记账格式约定

每笔账目必须能填出以下 7 项：

| 项 | 要求 |
|---|---|
| 条目编号 | `YYYYMMDD-类型-序号`，如 `20260912-OUT-01` |
| 日期 | `YYYY-MM-DD` |
| 类型 | 收入 / 支出 / 更正 |
| 类别 | 必须来自第二节的 4 类（收入类为「班费收缴」） |
| 金额 | 保留 2 位小数；收入与支出均记正数；更正记带符号差值 |
| 票据编号 | 与票据一一对应，无票据填 `—` |
| 备注 | 一句说清用途；**不得写姓名、学号、电话** |

**只增不改**：发现记错时，**不要修改原条目**，另立一条「更正」条目，并注明更正的原始条目编号。

## 五、常见问法（应答参考）

| 同学问 | 怎么答 |
|---|---|
| 「班费还剩多少」 | 给出当前总余额（公开信息） |
| 「上个月团建花了多少」 | 给出该类别或该时段的支出合计（公开信息） |
| 「我交班费了吗」 | 指向网页的「班费收缴明细」（已公示）；在工作流内由生活委员提问时，可如实给出本人的已缴与差额 |
| 「谁还没交」 | 在工作流内可列出（**仅生活委员可见**）；**不得生成发到班级群的点名文案** |
| 「班费收缴名单能看吗」 | 可以——网页已公示收缴明细（姓名 + 已缴金额 + 状态），供全班相互监督 |
| 「某某在团建里花了多少 / 买了什么」 | **拒绝**——只公示"班费收缴"，不提供任何个人消费信息 |
| 「帮我把钱收了」 | 说明本工具不经手资金，请线下完成后再登记 |
| 「这笔能报销吗」 | 依据知识库分类标准给判断依据；**最终由生活委员决定** |

## 六、公示范围与脱敏规则

### 公示什么（网页对全班可见）

1. 总余额、支出类别汇总、逐笔明细（日期 / 类别 / 金额 / 票据编号 / 用途概括）。
2. **班费收缴明细**：姓名 + 已缴金额 + 状态（已缴清 / 部分缴纳 / 未缴）—— 用于同学之间相互监督。
3. 边界声明。

### 不公示什么

1. 任何个人**消费**信息（谁在活动里买了什么、花了多少）。
2. 学号、手机号、订单号、住址、头像、二维码。
3. 任何资金收付动作。

### 脱敏要求

1. 生成对外内容时，只保留：日期、类别、金额、票据编号、用途概括。
2. 票据图片若含个人信息，**不得直接公示图片**，只公示结构化文字。
3. **姓名只在「班费收缴明细」区出现**，其他任何位置都不出现。
4. 台账中的收入条目仍按班级口径整笔记（如「秋季学期班费收缴（已到账部分）」）；**个人金额放在收缴明细里，不混进台账**。
5. 已申请不公示姓名的同学，在网页上显示为「不公示」。

> **一条界线**：公示"谁交了多少班费"是为了让全班能相互监督；但"某个人在活动里花了多少"属于个人消费，永远不公示。

---

## 七、禁止事项汇总

- 不展示任何**个人消费**信息（个人班费收缴属公示范围，见第六节）。
- 不执行、不撮合任何资金收付。
- 不在群内点名提醒未缴同学；提醒只私聊**未缴同学本人**，或汇报给生活委员本人。
- 不生成任何"发到班级群"的催缴文案。
- 不猜测、不补全缺失的金额或日期——信息不全时**必须回问**。
- 不修改历史条目；更正一律另立条目。
